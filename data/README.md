# PCAP Multimodal Data Dictionary & Archival Governance (`data/`)

This directory stores the structured archival metadata, L2-normalized 768-dimensional `OpenCLIP ViT-L/14` visual embeddings, 4-bit `LLaVA-1.5-7B` iconographic transcripts, low-level HCI formal image metrics, and serialized R/STM mathematical objects generated across **Steps 01–08** of the `PCAP_CLIP_and_LLaVA.ipynb` pipeline.

---

## 1. Ethical Governance & Zero-Image Storage Policy

In accordance with the **Prison Creative Arts Project (PCAP)** copyright notice, incarcerated artists retain full copyright and moral rights over their artwork. To respect artist sovereignty and transformative fair-use standards (*Distant Viewing*, Arnold & Tilton, 2023, pp. 55, 223):
* **Zero Persistent Image Binaries:** No `.jpg`, `.png`, or `.webp` image files are stored in `data/`. During Steps 02 and 03, image bytes are streamed into volatile RAM (`io.BytesIO`), converted into non-reconstructive mathematical feature vectors (`CLIP`) or descriptive text annotations (`LLaVA`), and immediately purged from memory (`del buffer`).
* **Direct Archival Attribution:** Every row in `pcap_master_metadata.csv`, `pcap_clip_embeddings.parquet`, and `pcap_tidy_corpus.rds` preserves its canonical `item_id` and `omeka_web_url` (`https://dcc.carceralstateproject.lsa.umich.edu/s/pcap/item/{item_id}`) so researchers can view the original artwork directly on the University of Michigan portal.

## 3. Detailed Schemas

### 3.1 `pcap_master_metadata.csv` & `pcap_clip_embeddings.parquet`
`pcap_clip_embeddings.parquet` contains all 15 columns from `pcap_master_metadata.csv`, followed by the **6 Theoretical Axis Cosine Similarity Scores** and **768 L2-Normalized Embedding Dimensions**:

* **Archival Provenance Columns (1–15):**
  * `item_id` (`character`): Unique Omeka S database item identifier (`o:id`).
  * `identifier` (`character`): PCAP exhibition log/catalog code (`dcterms:identifier`, e.g., `DPEA_ART4_0037`).
  * `title` (`character`): Artwork title (`o:title` / `dcterms:title`; defaults to `"Untitled"`).
  * `raw_date` (`character`): Raw date string (`dcterms:date` / `dcterms:created`).
  * `exhibition_source` (`character`): Annual exhibition or collection source (`dcterms:source` / `dcterms:isPartOf`, e.g., `"26th Annual Exhibition of Art by Michigan Prisoners"`).
  * `artist_name` (`character`): Creator name (`dcterms:creator`; defaults to `"Anonymous / Unlisted Artist"`).
  * `facility_raw` (`character`): Michigan Department of Corrections (MDOC) facility string (`dcterms:spatial`).
  * `medium_raw` (`character`): Raw material medium description (`dcterms:medium`, e.g., `"Soap and ink"`, `"Colored Pencil, Ink, Paint, Television Screen"`).
  * `subject_tags` (`character`): Curatorial subject/gallery tags (`dcterms:subject`).
  * `visual_description` (`character`): Archival visual description if present (`dcterms:description`).
  * `artist_statement` (`character`): Incarcerated artist's statement if archived (`bibo:content` / `dcterms:abstract`).
  * `rights` (`character`): Copyright statement (`dcterms:rights`).
  * `media_id` (`character`): Omeka S attached media object ID (`o:media[0]['o:id']`).
  * `image_url` (`character`): Resolved direct URL to the large/original image derivative used for ephemeral streaming.
  * `omeka_web_url` (`character`): Canonical public web URL for the item record.
* **6-Axis Zero-Shot CLIP Cosine Similarity Columns (16–21):**
  * `score_surveillance_biometric` (`float32`): Cosine similarity to Panoptic Surveillance ensemble prompts, orthogonalized via **Candidate B Contrastive Concept Subtraction** ($\alpha = 0.25$) against close-up crying/reflective eye portraiture confounders (90th percentile $\tau_{0.90} = 0.1724$).
  * `score_carceral_containment` (`float32`): Cosine similarity to steel bars, razor wire, locked cell doors, and shackles ($\tau_{0.90} = 0.1942$).
  * `score_bodily_autonomy` (`float32`): Cosine similarity to defiant self-portraiture, direct counter-gaze, and bodily sovereignty ($\tau_{0.90} = 0.1863$).
  * `score_tactile_disalienation` (`float32`): Cosine similarity to richly textured handmade craft, impasto, vibrant nature, wildlife, and open horizons ($\tau_{0.90} = 0.1913$).
  * `score_digital_mediation` (`float32`): Cosine similarity to prison telephones behind plexiglass, video visitation monitors, digital screens, and kiosks ($\tau_{0.90} = 0.1639$).
  * `score_state_bureaucracy` (`float32`): Cosine similarity to prisoner ID numbers, barcodes, mugshot placards, state forms, and tally marks ($\tau_{0.90} = 0.1890$).
* **Visual Embedding Columns (22–789):**
  * `clip_001` through `clip_768` (`float32`): L2-normalized (`norm = 1.00000`) `OpenCLIP ViT-L/14` (`openai`) visual representation vector.

### 3.2 `pcap_llava_interrogations.jsonl`
Each line is a valid UTF-8 JSON object containing:
* `item_id`, `title`, `sampling_stratum` (`baseline_control` or `high_signal_<axis>`), and the 6 `score_*` floats.
* `formal_brightness` (`float`): Mean pixel intensity $\in [0, 1]$ across a $128 \times 128$ RGB thumbnail (Arnold & Tilton, 2023, Ch. 3, pp. 64–65).
* `formal_saturation` (`float`): Mean pixel chroma ($\max(R,G,B) - \min(R,G,B)$) across the artwork.
* `formal_warm_ratio` (`float`): Proportion of non-grayscale pixels ($\text{chroma} > 0.10$) where $R \ge B$.
* `llava_model` (`string`): `"llava-hf/llava-1.5-7b-hf"`.
* `llava_description` (`string`): Deterministic (`do_sample = False`, `repetition_penalty = 1.12`) iconographic transcription.
  * *Methodological Note on $N = 2,174$ Corpus Size:* Because `Step 03` uses fault-tolerant append-only checkpointing (`open(..., "a")`), `pcap_llava_interrogations.jsonl` preserves both the initial $N = 1,200$ stratified run and the $N = 974$ newly ranked exemplars selected after the Candidate B contrastive surveillance upgrade, yielding **2,174 unique artwork transcripts** after deduplicating by `item_id` in `Step 05`.

### 3.3 `pcap_tidy_corpus.rds`
Adds the following normalized analytical variables to the 13,546-artwork metadata table:
* `clean_year` (`integer`): Verified exhibition year (1996–2025) parsed via 3-tier regex (direct year $\rightarrow$ $1995 + N$ from `"Nth Annual Exhibition"` $\rightarrow$ `-YY` identifier suffix). Left as `NA` when undated to prevent artificial concentration in temporal regressions (`Step 07`).
* `year_imputed` (`logical`): `TRUE` if `clean_year` was missing in raw metadata ($n = 120$ undated records out of $13,546$; $99.1\%$ verified date coverage).
* `clean_year_stm` (`integer`): Median-imputed year (`2012`) used strictly for the `stm` prevalence spline prior (`~ s(clean_year_stm) + medium_category`) so undated transcripts are not dropped by `prepDocuments`.
* `half_decade` (`character`): `"1996-1999"`, `"2000-2004"`, `"2005-2009"`, `"2010-2014"`, `"2015-2019"`, `"2020-2024"`, or `"Undated Record"`.
* `era_window` (`character`): `"Pre-Digital Era (1996-2009)"` vs. `"Carceral-Digital Turn (2010-2024)"`.
* `medium_category` (`factor`): 4-level Carceral Materiality Taxonomy (`"Contraband/Found Carceral Material"`, `"Mixed/Sculptural"`, `"Graphite/Ink on Paper"`, `"Standard Paint/Canvas"`).
* `security_level` (`character`): Parsed MDOC facility classification (`"Level I-II (Minimum / Low-Medium)"`, `"Level II-IV (Multi-Level Security)"`, `"Level IV-V (High / Maximum)"`, or `"Unspecified MDOC Facility"`).
* `disalienation_index` (`numeric`): Standardized net score $Z(\text{Tactile} + 0.5\cdot\text{Autonomy}) - Z(\text{Containment} + 0.5\cdot\text{Bureaucracy})$.
* `umap_1`, `umap_2` (`numeric`): 2D cosine UMAP coordinates.
* `visual_cluster_id` (`integer` 1–6) & `visual_cluster` (`character` `"Cluster 1"`..`"Cluster 6"`): K-means macro-visual cluster assignments.
